Barbearia Premium

Comandos úteis para reutilizar este template com a Skill criada:

```text
Usa $premium-barbershop-websites e este template da Barbearia para criar um novo site premium para uma barbearia chamada [NOME], localizada em [CIDADE/BAIRRO].
```

Exemplo mais completo:

```text
Usa $premium-barbershop-websites e adapta o template atual para uma nova barbearia premium chamada Barbearia Monte Real, em Cascais.
Quero português de Portugal, estética masculina de luxo, serviços realistas, preços em euros, novos barbeiros, novos testemunhos, nova morada, novo mapa e copywriting profissional.
```

Para mudar só a marca/conteúdo:

```text
Usa $premium-barbershop-websites. Mantém o design atual, mas transforma o site para a barbearia [NOME], em [LOCAL]. Atualiza textos, serviços, preços, equipa, testemunhos, contacto, mapa e imagens.
```

Para criar outro estilo dentro da mesma base:

```text
Usa $premium-barbershop-websites e o template atual como base. Cria uma versão mais [clássica/moderna/minimalista/luxury] para uma barbearia em [LOCAL], sem perder o nível premium.
```

Para pedir acabamento final:

```text
Usa $premium-barbershop-websites para fazer uma auditoria premium ao site: espaçamentos, textos, responsividade, mapa, galeria, serviços, footer, hero e sensação geral de portfólio.
```
